# Hospital Management System (HMS) MVP

A full-stack Hospital Management System built with the MERN stack.

## Tech Stack
* MongoDB (Atlas)
* Express.js
* React.js
* Node.js

## Roles
Admin, Receptionist, Doctor, Nurse, Pharmacist, Lab Technician, Accountant, Patient

## Setup
1. Clone the repository
2. Run cd server && npm install
3. Create a .env file in the server folder
4. Run npm run dev to start the backend
5. Open a new terminal, run cd client && npm install
6. Run npm start to start the frontend

## API Base URL
http://localhost:5000/api
